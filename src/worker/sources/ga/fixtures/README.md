### Georgia Burn Permits

The live adapter GETs `https://firestore.googleapis.com/v1/projects/georgiaburnpermits/databases/(default)/documents/counties/{COUNTY}?mask.fieldPaths=name&mask.fieldPaths=enabled` to confirm enrollment. It sends a read-only POST to `https://firestore.googleapis.com/v1/projects/georgiaburnpermits/databases/(default)/documents/counties/{COUNTY}:runQuery`. The query selects `excludedDates` with only the `date` and `reason` fields, a limit of eight and a half-open range from one Eastern midnight to the next. The fixtures retain the API's result and `readTime` metadata.
