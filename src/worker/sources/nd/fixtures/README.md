# North Dakota Department of Emergency Services fixtures

Both JSON files are unmodified attribute-only responses. The declarations query returned 108 records, including 53 counties. The rating query returned 53 county records. The declarations script ran at 03:45 Central on November 24, but the fire-danger layer still carried the November 23 rating when captured. There was no active Red Flag Warning in the state. The tests use these real responses and change selected fields to exercise fresh higher ratings and warning windows.

The Daily Restrictions dashboard uses the desktop and mobile WebMaps below. The desktop map's renderer and popup specify the threshold comparisons, the separate advance-notice field and the Extreme open-burning rule. The Fire Danger dashboard uses `DatePublished` for the displayed report date. Its Arcade expression describes an early-morning NWS run and a displayed 6 a.m. update. The previous day's issuance was encoded as 04:16 UTC and had an actual ArcGIS edit at 12:00 UTC. Matching the joined and original declaration records confirms that start and rescission encode Central wall time in the daily layer. The expiration field already carries a UTC instant. The signed Mercer and Oliver orders require contact before large burns at Low or Moderate. Their actual prohibitions start at High. McLean's signed declaration uses Very High, Extreme or a Red Flag Warning. The signed McKenzie order prohibits open and controlled burning, with an exception for specified grills. Sioux and Burke require fire-authority approval for covered burns. Slope delegates decisions to the district fire chief. Divide uses its own rating and requires local fire chief approval for covered open burning. The Little Missouri National Grassland order specifies Slope, Golden Valley, Billings and McKenzie. The daily map also has a Dunn County polygon, so that USFS row is excluded. The signed wording applies when the map still identifies the reviewed edition.
