The fixture preserves the publisher's county names, codes and timestamps. It omits unrelated WordPress object metadata. All 46 flags were `--no` with post dates from November 16 through 23. - **Production lookup.** The Worker uses the same read-only JSON POST as the public form's county selector, `POST https://www.scfc.gov/wp-json/scfcapi/v2/burnstatusmessage` with `Content-Type: application/json` and a body such as `{"county":"183"}` for Horry. Direct POSTs matched the GET captures for the sampled counties. The public script documents `--yes` as a closure. It generates the displayed date from the visitor's clock, so the parser checks the underlying WordPress UTC post date against the current Eastern date. The regional source IDs follow the Commission's official administrative regions.
