## Emergency orders and other authorities

- Illinois EPA and the Pollution Control Board regulate open burning under 415 ILCS 5/9(c) and 35 Ill. Adm. Code 237. Cities and counties can impose local restrictions. Under 70 ILCS 705/8.20(d), a fire district chief or designated officer can order a temporary district ban with board authorization and the specified fire-risk conditions. Coordinated district actions can cover an entire county. The General Assembly HTML endpoints had a certificate-chain failure on direct GET. [State statute](https://www.ilga.gov/documents/legislation/ilcs/documents/041500050K9.htm) · [Board rules](https://pcb.illinois.gov/documents/dsweb/Get/Document-11988/PART%20237%20-%20OPEN%20BURNING.pdf) · [District authority](https://www.ilga.gov/documents/legislation/ilcs/documents/007007050K8.20.htm) · [Iroquois County example](https://iroquoiscountyil.gov/county-news/emergency-management-agency/county-wide-burn-ban-officially-lifted)
